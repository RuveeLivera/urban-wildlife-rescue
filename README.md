## Project Overview

The Urban Wildlife Rescue Coordination System aims to improve the management and coordination of wildlife rescue activities in urban areas.

The application allows users to report incidents involving injured, trapped, displaced or abandoned animals. It records incident information, calculates rescue priorities, identifies suitable rescue teams and tracks each incident through to completion.

The system is developed using Object-Oriented Programming principles to maintain a structured, modular and maintainable codebase.

---

## Key Features

- **Incident Management:** Register, view and manage wildlife rescue incidents.
- **Priority Calculation:** Automatically classify incidents into Critical, High, Medium and Low priority levels.
- **Animal Management:** Maintain information about animals involved in rescue incidents.
- **Rescue Team Management:** Register and manage available rescue teams.
- **Team Matching:** Identify suitable rescue teams based on incident requirements.
- **Incident Tracking:** Assign teams and update rescue incident statuses.
- **File Handling:** Store and retrieve system data using CSV files.
- **Report Generation:** Generate rescue-related reports.
- **Exception Handling:** Handle unexpected errors and invalid operations.
- **Concurrent Processing:** Support concurrent operations where required.
