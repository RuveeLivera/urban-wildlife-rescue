## Description
A Java console application that helps a wildlife rescue organisation manage reports of injured, trapped, displaced or abandoned animals in urban areas. The system records incidents, calculates a priority score, matches suitable rescue teams and tracks each rescue until it is completed.

## Features
- Report and view incidents
- Automatic priority scoring (Critical, High, Medium, Low)
- Rescue team registration and matching
- Team assignment and incident status updates
- CSV file storage and rescue report generation
- Exception handling and concurrent processing

## Requirements
- Java JDK 17 or newer

## Project Structure
- `src/` Java source code
- `data/` CSV data files

## How to Run
1. Open the project in IntelliJ IDEA.
2. Run the `Main` class.
3. Choose an option from the console menu.
